# 户型图 → 离线 3D 空间

把用户这张图的空间关系写成可核对的数据，再用随附模板生成离线网页。默认直接显示 3D 全景，不添加开场视频、自动播放动画或外部网站登录。

## 还原与建模

先检查现有文件，若在已有模型上修改则保留其坐标、尺寸依据和用户选择。新建模型时：

- 按图中标注分别校准横轴和纵轴；有分段尺寸时按分段刻度定位。不要把截图像素当成准确尺寸，也不要把墙轴线尺寸当作房间净尺寸。
- 标清玄关、客餐厅、卧室、厨卫、阳台的连通关系。门洞留在墙上，家具不要堵门。开放空间不需要为了命名人为加墙。
- 图上有尺寸就采用尺寸；未标出的高度、厚度和家具可使用合理住宅值，并写入 `assumptions`。缺少任何已知尺寸时，索取一个尺度或明确交付是估算比例。
- 不推断承重性、真实北向和日照城市。夜景是效果预览，不是照度计算。用户图片和地址不进入可公开的示例仓库。

读取 [references/spec-format.md](references/spec-format.md)，写出毫米制 JSON。它是本模板自己的格式，不是 house-plan-designer 的 HouseSpec。模型中 1000 mm 对应 1 个 Three.js 单位。

```text
node <skill目录>/scripts/build.mjs <户型.json> --out <交付.html>
```

构建脚本无 npm 依赖：读取随附 Three.js、界面模板和可选原图，内联为一个 HTML。原图仅按 JSON 的 `underlay` 路径读取。不要为了生成网页上传图片，也不要将已有账号凭据、绝对用户路径或个人户型写进公共仓库。

## 交互与视觉

保持原图的房间位置与尺度，装修材质是示意。默认提供：

- 直接进入无顶盖的 3D 鸟瞰；2D 彩平采用同一份模型坐标。
- 拖动环顾、WASD 自由飞行、E/Q 升降、Shift 加速；点击房间按钮平滑飞入，随时回全景。
- 原图叠加用于核对；透视墙体用于观察遮挡；昼夜切换和室内暖光预览。
- 手机方向按钮、全屏和简洁操作提示。自由飞行允许穿墙，界面须明确这一点。

需要更细的门窗、定制家具或光照时扩展现有模板或数据，不要声称模板已经实现没有验证过的能力。用户明确要开场或视频时再单独制作，不要把它加入默认入口。

## 检查与交付

按 [references/verification.md](references/verification.md) 检查。构建器会拒绝非有限坐标、非正尺寸、无效开洞与不受支持的家具类型；这不代替对图检查。

有浏览器工具时，在 `file://` 和离线环境验证实际渲染、2D/3D、房间飞入、原图开关、透视与夜景；检查控制台，并查看桌面和手机截图。浏览器测试只使用现有浏览器和可用自动化工具，缺失时说明实际验证范围，不自动下载浏览器。

交付可直接打开的 HTML、至少一张真实渲染的全景截图，以及尺寸估算说明。只在用户明确要求上传/发布时进行外部写入。发布 Skill 前用虚构示例验证可复用性，排除用户原图、个人路径和凭据。
